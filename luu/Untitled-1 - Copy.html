🌍 Tạo thế giới mới cho riêng mình

Khái niệm về world (thế giới mô phỏng)

World (Thế giới) là một tệp tin chứa toàn bộ thông tin như: vị trí các vật thể, hình dáng của chúng, cách chúng tương tác với nhau, màu sắc của bầu trời, cũng như các định nghĩa về trọng lực, ma sát, khối lượng của vật thể... Nó xác định trạng thái ban đầu của một phiên mô phỏng.

💡 Bạn có biết: Mọi thứ ta thấy trên màn hình 3D (robot, vật thể, vị trí, kích thước) đều được mô tả bằng văn bản. Bạn hoàn toàn có thể copy/paste nhanh hoặc nhân bản robot chỉ bằng vài dòng code. File .wbt có thể mở bằng VS Code, Notepad++.

🛠️ Thực hành tạo thế giới

  • Bước 1: Mở webots trên màn hình. (Lưu ý: Bạn nào chưa tải webots, hãy tham khảo slide Webot Installation & Simple Usage Guide (2025)).
  • Bước 2: Nháy chọn nút File ở góc trái -> Nhấn New -> Chọn New Project Directory.
  • Bước 3: Nhấn Next, tạo 1 folder mới ở ổ D (hoặc ổ E) để chứa dự án mới thay vì chọn đường dẫn đề xuất.
  • Bước 4: Đặt tên cho project mới. Tick hết vào các ô, đặc biệt là ô “Add a rectangle arena”. Nhấn Finish.
⚠️ Lưu ý: Không lưu project trong thư mục mặc định của Webots. Khi mở Sample World, luôn sử dụng chức năng Save World As... để tránh làm hỏng các file mẫu.

📦 Thực Hành Thả Vật Thể

Trong giao diện của Scene Tree, các trường dữ liệu được biểu diễn dưới nhiều màu khác nhau (phụ thuộc vào màu nền của chúng) nếu như chúng khác với các giá trị mặc định ban đầu.

  • Bước 1 - Thêm vật thể: Nhấp đúp RectangleArena -> Nhấn nút Add (+) -> Chọn PROTO nodes / objects / factory / containers / WoodenBox(Solid).
  • Bước 2 - Chỉnh kích thước & vị trí: Nhấp đúp vào WoodenBox, thay đổi size thành 0.1 0.1 0.1 và translation thành 0 0 0.05.
  • Bước 3 - Di chuyển & Sao chép: Nhấn giữ Shift + chuột trái để kéo thùng. Dùng Ctrl+C, Ctrl+V để sao chép.
  • Bước 4 - Xoay: Dùng các mũi tên màu xanh dương để xoay thùng quanh trục thẳng đứng.

🤖 Thêm Robot E-puck & Tạo Controller

E-puck là một robot nhỏ sở hữu hệ thống bánh xe vi sai, đèn LED và cảm biến khoảng cách. Để thêm robot, tìm nút WoodenBox cuối cùng -> Add -> PROTO nodes / robots / gctronic / e-puck / E-puck (Robot).

⏳ Quy tắc thời gian: Luôn Pause -> Reset -> Modify -> Save. Đảm bảo đồng hồ hiển thị 0:00:00:000 trước khi chỉnh sửa thế giới để tránh sai số.

💻 Lập trình Controller

Vào menu File / New / New Robot Controller… -> Chọn ngôn ngữ C -> Đặt tên epuck_go_forward. Sau đó liên kết nó vào trường controller của E-puck trong Scene Tree.

#include <webots/robot.h>
#include <webots/motor.h>

#define TIME_STEP 64
#define MAX_SPEED 6.28

int main(int argc, char **argv) {
    wb_robot_init();

    WbDeviceTag left_motor = wb_robot_get_device("left wheel motor");
    WbDeviceTag right_motor = wb_robot_get_device("right wheel motor");
    
    // speed control
    wb_motor_set_position(left_motor, INFINITY);
    wb_motor_set_position(right_motor, INFINITY);

    wb_motor_set_velocity(left_motor, 0.1 * MAX_SPEED);
    wb_motor_set_velocity(right_motor, 0.1 * MAX_SPEED);

    while (wb_robot_step(TIME_STEP) != -1) { }
    
    wb_robot_cleanup();
    return 0;
}

Sau khi lưu mã nguồn, nhấn Build (biểu tượng bánh răng). Cuối cùng nhấn Reset và chạy mô phỏng. Robot của bạn sẽ di chuyển liên tục!
